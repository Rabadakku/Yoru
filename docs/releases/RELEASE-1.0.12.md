# Yoru 1.0.12

A clearer study workspace, with faster task finding and a timer that stays visible.

- **Today:** Clock in/out sits immediately below the timer, ahead of the trail.
  A daily-goal bar shows recorded time against the same goal as the heat map,
  with a written completion state when the goal is reached.
- **Across pages:** a live recording indicator returns to Today in one click.
  Navigation has more space between destinations, readable active colours, and
  a written date; the time zone remains available in the date's tooltip.
- **Tasks:** search titles, notes and tags without case sensitivity. Search
  combines with every view, including Calendar. Clear or Escape restores the
  list. View, sort, month and query survive navigation within the open window.
  Reordering stays disabled while searching to protect the complete manual order.
- **Appearance:** light-theme primary actions and selected controls now meet
  4.5:1 text contrast, including hover and pressed states. Rounded control fills,
  outlines and keyboard focus rings use matching corner geometry.
- **Release checks:** installers wait for the full suite on Java 22, the bundled
  runtime version. Release notes are included automatically with the installers.

No vault schema changes. Existing study history, settings and game saves are
preserved. Yoru continues to ship no game, game artwork or music.

Validation includes the full isolated test suite, 100 page renders across five
themes and two window sizes, and long-name layout checks at 100%, 125%, 150%
and 200% text. Clean-machine installation and full native gameplay have not
been revalidated for this UI release.
