# Yoru 1.0.19

## Small details, smoother workspace

- Open-page tabs use one quiet surface instead of separate accent-filled pills.
  Long titles shorten visually while preserving their full tooltip and keeping
  the close button reachable.
- Scrollbars have slim rounded thumbs, clearer hover/drag feedback and no
  decorative arrow buttons. Scrolling with the keyboard, wheel and track remains.
- Shared buttons consistently show hover feedback.
- The Edit menu enables commands according to the focused field, text selection
  and actual undo/redo history. Read-only fields and password fields keep their
  appropriate restrictions. Text context menus also reflect undo/redo history.
- Sidebar destinations expose their selected state to accessibility tools.
- The README now explains the current interface, Pages, persistent Anki settings,
  offline summaries and exports, with current synthetic screenshots.

No vault migration. The broader UI ticket #63 remains open for continued
page-specific refinement and owner feedback.
